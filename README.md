# 🧾 말랑 API 영수증 · 크레딧

마리나라 기본 홈 화면에서 API 사용량과 크레딧을 확인할 수 있는 개인 확장입니다. **말랑 홈의 영수증과 크레딧 기능을 분리**했기 때문에 말랑 홈 없이 사용할 수 있습니다.

## 무엇을 볼 수 있나요?

- **API 영수증**: 오늘과 이번 달의 사용액, 모델별 사용 내역, 월말 예상 금액을 보여 줍니다.
- **단가와 통화 설정**: 영수증의 `Edit`에서 모델 단가, 사이트별 가격 설정, 표시 통화와 환율을 조정할 수 있습니다.
- **크레딧**: `＋ 크레딧 추가`로 Google Cloud, 중계 API, NanoGPT, DeepSeek, OpenRouter 등의 사용량이나 잔액을 확인할 수 있습니다. 서비스에 따라 API 키 또는 추가 설정이 필요합니다.

영수증은 별도 계정을 연결하지 않아도 마리나라 채팅에 기록된 토큰과 모델 단가를 이용해 사용액을 계산합니다. **이 값은 추정치**이며 실제 청구액과 다를 수 있습니다. 서비스 연결 시 지원하는 항목은 사이트의 사용 내역이나 Google 모니터링 정보를 활용합니다.

## 설치

### GitHub 확장 관리자로 설치

마리나라의 GitHub 확장 관리자에서 아래 레포지토리를 추가하고 설치한 뒤 확장을 켜고 새로고침해 주세요.

```text
https://github.com/tlsiddl/mallang-receipt-credit
```

설치 후 기본 홈 화면에서 영수증을 확인할 수 있습니다.

### ZIP으로 설치

개인 확장 설치용 ZIP을 받은 경우, 마리나라 **설정 → 개인 확장 → 설치**에서 ZIP을 선택하고 실행을 허용한 뒤 새로고침해 주세요.

## 사용 방법

1. 기본 홈의 **API 영수증 · 크레딧** 영역에서 영수증을 확인합니다.
2. 영수증 오른쪽의 **Edit**에서 통화와 단가를 확인하거나 변경합니다.
3. 사이트 잔액이나 별도 사용 내역이 필요하면 **＋ 크레딧 추가**를 눌러 서비스를 선택하고 필요한 정보를 입력합니다.
4. 새로 집계하려면 영수증의 **↻** 버튼을 누릅니다.

## 알아두세요

- 말랑 홈에도 같은 기능이 들어 있습니다. 중복 실행을 피하려면 말랑 홈을 끄고 이 확장을 사용해 주세요.
- 채팅 기록에 남은 사용량을 바탕으로 계산하므로 기록되지 않은 호출이나 실제 청구 방식에 따라 차이가 생길 수 있습니다. 정확한 청구액은 각 서비스에서도 확인해 주세요.
- 마리나라 2.5.1에서 기본 홈 표시와 영수증 집계를 확인했습니다. 독립 확장의 크레딧 서비스 연결과 iOS Safari 동작은 아직 별도로 확인하지 못했습니다.
