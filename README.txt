말랑 API 영수증과 크레딧 0.1.0 (시험판)

마리나라 설정 → 개인 확장 → 설치에서 zip을 선택하고, 확장을 켠 뒤 새로고침하세요.
말랑 홈과 동시에 켜지 말고 말랑 홈을 끈 다음 기본 홈에서 사용하세요.

영수증의 Edit에서 통화와 단가를 조정할 수 있고, 크레딧 추가 버튼으로 사이트를 선택하고 계정 정보를 입력할 수 있습니다.
기존 말랑 홈의 설정과 기록이 자동 이전되는지는 확인되지 않았으므로, API 정보와 단가 등을 새로 입력해야 할 수 있습니다. 기존 기록은 삭제하지 마세요.
이 시험판은 실제 마리나라와 iOS Safari에서 아직 검증하지 않았습니다. 실제 금액과 사이트의 공식 사용량을 비교해 주세요.
